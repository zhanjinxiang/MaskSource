WHY MASKSOURCE

解决视觉语言模型的版权与溯源难题

VLM 在智能问答、图像分析、创意内容生成等场景中快速应用，但也带来了模型窃取、生成内容盗用、版权归属不清等问题。

模型资产易被窃取

高价值模型可能被复制、微调或盗用，需要可远程验证的所有权证明。

生成内容难以追责

AI生成图文在网络传播后，来源不透明，侵权追责和责任定位困难。

传统水印适配不足

单模态水印难以适配跨模态交互，容易损害语义对齐或被攻击移除。

CORE FEATURES

双盾双溯源：模型与内容双层防护

模型水印生成

利用 DWT 与可逆网络生成视觉无损水印图像，并构造身份编码触发文本。

双密钥嵌入

通过提示-图像联合触发机制，降低单触发器被伪造或绕过的风险。

多比特文本水印

将用户ID、时间戳等信息编码为复杂二进制序列，实现精准身份追踪。

熵自适应策略

在高熵生成区域动态嵌入水印，在保证文本质量的同时提升容量。

ARCHITECTURE
