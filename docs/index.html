MaskSource 基于「双盾双溯源」的视觉语言模型
全链路版权保护体系

面向视觉语言模型（VLM）的版权保护与溯源系统。通过「提示-图像双密钥联合触发」与「熵引导多比特文本水印」两大核心机制， 同时解决模型所有权证明与生成内容来源追踪问题，构建从模型到内容的闭环保护链路。

📄 作品摘要

视觉语言模型凭借其强大的跨模态理解与生成能力，在图像描述生成、视觉问答、创意内容生成等领域展现出巨大潜力。 然而，模型窃取、生成内容盗用等侵权行为日益频繁，严重威胁模型安全与内容可信性。

本作品提出一种面向视觉语言模型的版权保护与溯源方案。该方案通过融合后门与高容量水印技术，构建了模型与生成内容的双层防护体系： 在模型所有权验证上，我们利用「提示-图像」双密钥后门机制，其跨模态的联合触发条件有效规避了单一触发器的安全瓶颈； 在生成内容方面，则通过自适应多比特水印技术实现精准溯源。

实验表明，模型版权保护系统在微调和结构化剪枝等严苛场景下 WSR 稳定在 97% 以上； 生成内容版权保护系统实现了嵌入容量、检测准确率与文本质量的协同提升，容量达到 2.0+ bits/token， 困惑度降至 个位数区间。

✨ 核心特性

🔐

双密钥联合触发

提示-图像双模态同时满足方可激活水印，单一条件无法触发，破解难度指数级提升。

🧬

熵引导自适应嵌入

根据生成位置的不确定性动态调整嵌入强度，低熵区弱嵌入保自然度，高熵区强嵌入提容量。

📈

多列表高容量编码

2/4/8 动态列表映射，单位位置编码 1~3 比特，容量突破传统单比特瓶颈至 2.0+ bits/token。

🛡️

FGSM 对抗鲁棒训练

高频域对抗样本持续训练可逆网络，秘密恢复误差 MSE 较原始网络下降超 70%。

⚖️

MGDA 多目标协同

动态求解共享更新方向，协调效用损失、多触发器损失与单触发器约束，训练稳定高效。

🔍

确定性身份序列恢复

从「统计有无水印」升级为「精准恢复身份序列」，支持用户级内容追踪与可量化取证。

🏗️ 系统架构

🛡️ 第一盾

模型版权保护子系统

  • 水印生成（DWT + 可逆网络）
  • 水印嵌入（提示学习 + MGDA）
  • 水印验证（黑盒 + 跨模态溯源）
⟷
🛡️ 第二盾

生成内容版权保护子系统

  • 身份序列生成（SHA-256 + MD5）
  • 熵计算与多列表编码
  • Logits 偏置注入与提取
💻 统一客户端

VLM 版权保护系统

模型管理 · 对话交互 · 水印验证 · 权限分级 · 可视化取证

双盾双溯源架构：模型侧通过「提示-图像双密钥」保护模型本体版权；内容侧通过「熵引导多比特水印」追踪生成内容来源。 两条链路在统一客户端汇合，实现完整的争议处理与证据输出。
